# Saku Dashboard

SPA untuk Mini Wallet, dibangun dengan Next.js, React, Tailwind CSS, komponen shadcn/ui berbasis Radix, TanStack Query, TanStack Table, dan Recharts.

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Buka `http://127.0.0.1:3001`. Laravel API harus berjalan di `http://127.0.0.1:8000`.

Perintah verifikasi:

```powershell
npm run lint
npm run build
```

Dokumentasi setup, akun demo, kontrak API, arsitektur, dan keputusan keamanan tersedia di [README utama](../README.md).
